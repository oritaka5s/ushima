# Discover USHIMA — 鵜島を知る、瀬戸内を感じる。

瀬戸内海、愛媛県今治市の沖合に浮かぶ小さな島、鵜島（うしま）。

穏やかな海、行き交う船、島の集落、そして人々の暮らし。

鵜島には、村上海賊ゆかりの歴史、船や海運とともに育まれた文化、三十三観音、例大祭など、受け継がれてきた物語があります。

**Discover USHIMA** は、鵜島の自然・歴史・文化・暮らしを紹介し、島の魅力を未来へ伝えるためのWebサイトです。

## Explore USHIMA

- **島を知る** — 鵜島の風景と暮らし
- **村上海賊と歴史** — 瀬戸内の海と島をめぐる物語
- **船と産業** — 和船、造船、海運の歴史
- **文化と祭り** — 三十三観音、例大祭、受け継がれる文化
- **アクセス** — 鵜島への行き方と訪問のヒント
